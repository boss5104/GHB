# วางแผนหนี้ ธอส. (GH Debt Planner)

แอปวางแผนผ่อนชำระและวิเคราะห์หนี้ ธอส. (บัญชีบ้าน 4901 และบัญชีหอ 6367) — ไฟล์เดียว `index.html` เปิดใช้งานได้ทันที ไม่ต้องใส่รหัสผ่าน

## ความสามารถ
- ดีไซน์ใหม่ หรูหรา ทันสมัย รองรับ iPhone / MacBook และโหมดมืด-สว่างอัตโนมัติ
- เก็บข้อมูลใน **Google Sheet** และซิงค์อัตโนมัติทุกครั้งที่แก้ไข (ข้อมูลยังสำรองในเครื่องเสมอ ใช้งานออฟไลน์ได้)
- แจ้งรายการที่เปลี่ยนแปลงทุกครั้งที่อัปเดต + ประวัติการอัปเดตจากทุกอุปกรณ์ (บันทึกลงชีต “บันทึกการอัปเดต” ด้วย)
- ปุ่ม **รีเฟรช** ดึงข้อมูลล่าสุดจาก Google Sheet และตรวจหาเวอร์ชันใหม่ของแอป
- ปุ่ม **เพิ่มลงหน้าจอ** (iPhone: หน้าจอโฮม, MacBook: Dock) พร้อมไอคอนแอปในโฟลเดอร์ `icons/`
- วิเคราะห์โครงการประนอมหนี้ รายงานสรุป และบันทึก PDF

## ตั้งค่า Google Sheet (ครั้งเดียว)
1. สร้าง Google Sheet ใหม่ → เมนู **ส่วนขยาย → Apps Script**
2. วางโค้ดจาก [`google-apps-script/Code.gs`](google-apps-script/Code.gs) แล้วบันทึก
3. **Deploy → New deployment → Web app** · Execute as: **Me** · Who has access: **Anyone**
4. คัดลอก URL ที่ลงท้าย `/exec` ไปวางในแอป: เมนู ⋯ → **ตั้งค่า Google Sheet**
5. กด “คัดลอกลิงก์สำหรับอุปกรณ์อื่น” แล้วเปิดลิงก์นั้นบน iPhone/MacBook เพื่อเชื่อมต่อทันที

> ผู้ที่มี URL ของ Web App สามารถอ่าน/แก้ไขข้อมูลได้ — เก็บไว้เป็นความลับ
> หากต้องการให้ทุกอุปกรณ์เชื่อมต่ออัตโนมัติ ใส่ URL ไว้ในค่าคงที่ `DEFAULT_SHEET_URL` ใน `index.html`

## การเผยแพร่
เปิดใช้ GitHub Pages (Settings → Pages) แล้วเข้าใช้งานผ่าน `https://<user>.github.io/GHB/` — ต้องเปิดผ่าน https เพื่อให้ปุ่มเพิ่มลงหน้าจอและการทำงานออฟไลน์ใช้ได้เต็มที่

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอป |
| `manifest.webmanifest`, `sw.js` | ติดตั้งเป็นแอป / ใช้งานออฟไลน์ |
| `version.json` | แจ้งเตือนเมื่อมีเวอร์ชันใหม่ (อัปเดตพร้อม `APP_VERSION` และ `CHANGELOG` ใน `index.html`) |
| `icons/` | ไอคอนสำหรับ iPhone (`apple-touch-icon.png`), MacBook (`icon-1024.png`), favicon |
| `google-apps-script/Code.gs` | ตัวเชื่อม Google Sheet |
